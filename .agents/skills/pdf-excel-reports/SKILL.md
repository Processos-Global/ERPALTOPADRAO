# PDF and Excel reports
Locate the real view/service, template if any, permissions, queryset and existing export convention before editing. The project has ReportLab PDF generation in compras/services/ and pos_obra/relatorios.py, and openpyxl exports in financeiro/views/relatorios.py; use only relevant examples. Verify filter/period parity with the screen, financial totals through financial-integrity, ordering, units, timezone and filenames/content types. Escape untrusted text, guard formula injection in spreadsheet cells, avoid leaking private documents and use bounded memory for large exports. Validate generated bytes with a PDF/Excel reader, representative page or worksheet content, headers, empty results and authorized/unauthorized access using synthetic data in isolation. Do not publish files or use production data for testing.
