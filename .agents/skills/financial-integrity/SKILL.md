# Financial integrity
Trace real financial models, services, views, permissions and any links to compras or contratos. For each affected amount or indicator record source fields, formula, unit/currency, period, filters, granularity, decimal precision, rounding point and treatment of nulls, duplicates, reversals and denominator zero. Check whether joins or status filters duplicate values. Build independent reference cases from verified rules; label synthetic fixtures. Reconcile detail rows with totals and displayed/exported values. Preserve approval and audit behavior. Have the financeiro owner establish the expected result before backend/UI implementation and QA tests. Never treat sample figures as actual business data or mutate production records.
